# --- document extraction ---
openpyxl==3.1.5          # .xlsx

# These two ship compiled wheels, and a hard pin means no wheel for a Python newer than
# the pin — pip then tries to build from source and the install fails. A judge on a
# current Python would hit that on `pip install -r requirements.txt`, so they carry a
# floor rather than an equality. The Docker image pins Python instead (3.11-slim), which
# is where reproducibility actually matters.

# --- LLM fallback (degrades gracefully when absent or unkeyed) ---
# A floor, and the reason is not wheels this time. anthropic 0.39 passes proxies= to
# httpx.Client, which httpx removed in 0.28 — so `pip install -r requirements.txt` on a
# clean machine resolves a pair that cannot construct a client. It fails the way this
# codebase is designed to fail, by logging and falling back to rules-only, which means
# it fails SILENTLY: the site serves "rules-only" forever and nothing looks broken.
# That is exactly what production did until it was caught by hand. Every measurement in
# out/ was taken on 1.7.0; ship what we measured.
anthropic>=1.7.0
