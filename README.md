# averis-hackaton — SDOC Shipping Document Verification

Pipeline that reads a shipping-ops inbox and, for each email, classifies it and — for document-comparison requests — checks a draft Bill of Lading (BL) against the Shipping Instruction (SI) it should match.

Full task spec, architecture, data contracts and the day-by-day plan for the team live in the Claude project "hackaton":
- `hackathon-plan.md` — task, architecture, AWS deployment plan, judging criteria
- `hackathon-tasks.md` — step-by-step task split between the two contributors
